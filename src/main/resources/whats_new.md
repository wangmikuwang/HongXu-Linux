# 更新日志

虹叙 Linux 版的版本变化，新版本在上。安装包见 [Releases](https://github.com/wangmikuwang/HongXu-Linux/releases)。

## 1.2.0
- 🖥️ 更适合键盘鼠标：窗口较宽时左侧显示导航栏，内容保持适合阅读的宽度；Esc 或鼠标侧键返回；输入行动时 Enter 发送、Shift+Enter 换行；Ctrl + = / - / 0 缩放界面；记住窗口大小与位置。
- 🈶 界面统一为简体中文，不再因系统语言出现中英混杂；文件选择对话框也显示中文。
- 😀 Emoji 在没有彩色 Emoji 字体的系统上也能正常彩色显示（随应用附带 Noto Color Emoji）。
- 📦 安装后应用菜单显示「虹叙」；新增 Flatpak 打包支持。

## 1.1.0
- 📚 补齐内置剧情：此前 Linux 版只带了一小部分预置剧情与角色，现在包含与手机版相同的全部预设包。
- 🌈 新增 7 部剧情，覆盖半性恋、灰性恋、无浪漫倾向、全性恋、多性恋、流动性取向与不贴标签，含跨性别、非二元、性别流动与间性人角色；角色性取向选项同步扩充。
- ⚙️ 设置菜单的说明文字改为桌面版实际提供的功能。

## 1.0.0
- 🐧 虹叙首个 Linux 桌面版：提供 Debian / Ubuntu（.deb）与 Arch Linux 安装包，剧情、角色、AI 导演、存档与分享码导入和手机版一致。
- 🫧 液态玻璃、配色预设、内置楷体与自定义字体在桌面上同样可用；窗口可自由缩放。
- 📋 分享内容会复制到剪贴板或另存为 .wenyou 文件，二维码海报保存到「图片」文件夹；可从图片识别分享二维码导入。
- 🔄 启动时检查新版本，可在发布页面下载新的安装包覆盖安装，本地资料保留。
