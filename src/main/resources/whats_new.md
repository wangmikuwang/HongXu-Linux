# 更新日志

虹叙 Linux 版的版本变化，新版本在上。安装包见 [Releases](https://github.com/wangmikuwang/HongXu-Linux/releases)。

## 1.5.0
- 🍎 全新 Apple 主题：参照 Apple 人机界面指南重新设计。iOS 字阶（大标题 34、正文 17、脚注 13…）、分组背景与白色分组卡片、系统分隔线色；主页面使用左对齐大标题，宽窗口的侧边导航栏同样适配。
- 🎚️ Apple 主题下的控件改为 iOS 样式：绿色开关、少量选项用分段控件、其余选项改为「标题 · 当前值 ›」列表行；搜索框、筛选标签与小按钮使用无描边的灰色填充；输入框改为填充样式。
- 🫧 液态玻璃并入 Apple 主题：选择 Apple 即启用玻璃底栏，玻璃材质与底栏标签设置移到「液态玻璃」分组；新增「降低透明度」，开启后底栏改用不透明背景。其他界面风格不再显示玻璃选项。
- 🎨 强调色与系统红按对比度校准，文字链接在所有分组背景上都达到 4.5:1。

## 1.4.0
- 🔗 人物状态与后续剧情绑定：AI 会读到每项数值的含义（例如好感度 10 = 反感、冷淡，信任 90 = 完全信赖），角色的台词、语气和行动必须与当前状态一致；状态随剧情逐步变化，单项每轮最多 ±20；在控制台手动调整后，AI 从下一轮起直接按新状态演绎。
- 🌈 新增 6 部内置剧情与 12 位角色：太空星港的男性爱情、雪山押送的女性武侠、校园钟楼推理（分支剧本）、龙与面包店、跨性别大提琴手的乐团故事，以及一对相伴三十年的银发同志伴侣想办一场婚礼的海边民宿。（需开启 LGBT 内容显示）
- 🔤 内置完整版霞鹜文楷：恢复未删减的原版字体，生僻字也以楷体显示；新增 Medium 字重，标题与粗体使用真实字重。设置中显示为「霞鹜文楷」。
- 🎨 统一界面风格：页面标题栏统一居中，「设置」不再显示返回箭头；卡片、选项与输入框的圆角跟随所选界面风格，间距按 4dp 栅格整理。
- 📦 安装包因完整字体变大（约 +40 MB），换来更完整的显示效果。

## 1.3.0
- 🌐 新增界面语言：在「外观与主题 → 语言」可选跟随系统、简体中文、繁體中文（台湾常用词）或 English，全部界面文字即时切换，包括提示、对话框与用量统计。
- ✍️ AI 跟随界面语言写作：选择 English 或繁體中文后，新生成的剧情、角色、选项与导演回复都用该语言书写；已有剧情与角色保留原文。
- 🔤 内置楷体补充繁体常用字。
- 🎛️ 对局右上角的「⋯」菜单并入「控制台」：推进节奏、总结并开启新篇章、成就馆、切换 AI 服务、用量统计和导出对局文本都成为控制台里的独立选项。
- ✏️ 控制台可以手动调整人物状态：点人物卡上的「调整」，用滑杆修改好感度、信任等数值，添加或移除状态，编辑标记与穿着外观；保存后剧情按新状态继续。

## 1.2.0
- 🖥️ 更适合键盘鼠标：窗口较宽时左侧显示导航栏，内容保持适合阅读的宽度；Esc 或鼠标侧键返回；输入行动时 Enter 发送、Shift+Enter 换行；Ctrl + = / - / 0 缩放界面；记住窗口大小与位置。
- 🈶 界面统一为简体中文，不再因系统语言出现中英混杂；文件选择对话框也显示中文。
- 😀 Emoji 在没有彩色 Emoji 字体的系统上也能正常彩色显示（随应用附带 Noto Color Emoji）。
- 📦 安装后应用菜单显示「虹叙」；新增 Flatpak 打包支持。

## 1.1.0
- 📚 补齐内置剧情：此前 Linux 版只带了一小部分预置剧情与角色，现在包含与手机版相同的全部预设包。
- 🌈 新增 7 部剧情，覆盖半性恋、灰性恋、无浪漫倾向、全性恋、多性恋、流动性取向与不贴标签，含跨性别、非二元、性别流动与间性人角色；角色性取向选项同步扩充。
- ⚙️ 设置菜单的说明文字改为桌面版实际提供的功能。

## 1.0.0
- 🐧 虹叙首个 Linux 桌面版：提供 Debian / Ubuntu（.deb）与 Arch Linux 安装包，剧情、角色、AI 导演、存档与分享码导入和手机版一致。
- 🫧 液态玻璃、配色预设、内置楷体与自定义字体在桌面上同样可用；窗口可自由缩放。
- 📋 分享内容会复制到剪贴板或另存为 .wenyou 文件，二维码海报保存到「图片」文件夹；可从图片识别分享二维码导入。
- 🔄 启动时检查新版本，可在发布页面下载新的安装包覆盖安装，本地资料保留。
